# ⚡ Havizhan's Interactive Portfolio
A modern, highly interactive, and responsive developer portfolio built using the latest modern web technologies: **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**.
This portfolio is designed to showcase visual styling, front-end development skills, and creative interactive animations.
---
## ✨ Key Features
### 1. 📇 Interactive 3D Lanyard Card
* A physics-based, draggable 3D lanyard ID card built using **Framer Motion**.
* Responsive physics: elastic rope movement, rotational inertia, and mouse tracking.
* Dynamic role cycling text (`Student at UNS`, `Desainer Grafis`, `Frontend Dev`) with smooth slide-and-fade animations.
### 2. ⚡ Hacker-Style Profile Decryption
* Interactive terminal style button: **"Decrypt Developer Profile"**.
* Clicking the button triggers a simulated cascade of retro **"Error!" warning windows** popping up randomly and stacking on the screen.
* Once the scan finishes, a green **"Access Confirmed"** banner appears, followed by a typing effect to reveal the full developer biography.
### 3. 🛠️ Modern Design & Typography
* Dark-themed aesthetic utilizing Glassmorphism, grid pattern backgrounds, and soft ambient glows.
* Pixel-perfect typography and components using Tailwind CSS v4.
### 4. 📁 Project Showcase & Contacts
* Displays recent work (web design, software development, and UI/UX design) with direct live demo and code repository buttons.
* Integration of lightweight custom SVGs (GitHub, LinkedIn) to maintain compatibility and fast load times.
* Download button for full PPT portfolio containing projects list stored on Google Drive.
